# 핫딜연구소

**AI 기반 실시간 커뮤니티 핫딜 큐레이션 및 추천 플랫폼**
서버리스(Serverless) 아키텍처 위에서 데이터 수집, AI 분석, Vector DB 검색이 매끄럽게 연결되는 풀스택 프로젝트.

---

## 1. 문제 정의

커뮤니티 **핫딜** 문화란, 회원들이 원가 대비 할인율이 높은 상품 정보를 자발적으로 올리면 다른 이용자들이 그 정보를 보고 구매처로 몰려가는 방식으로 자리 잡아 있음. 좋은 할인 정보는 한 사이트에만 모여 있지 않고, 커뮤니티마다 글이 새로 올라오는 시점과 분위기도 서로 다름.

핫딜을 즐기는 사용자 입장에서는 **여러 커뮤니티를 돌아다니며** 좋은 글을 찾는 과정이 번거로웠고, **한곳에 모아서** 비교·열람하고 싶은 요구가 있었음. 또 일반적인 할인 소식과 달리 **순수 추천이 아닌 광고·바이럴성 게시**가 섞이면 판단이 어려워지므로, 이런 글을 걸러 내고 **신뢰할 만한 핫딜 위주로** 보고 싶었음.

이에 **여러 출처의 핫딜을 한 화면에 모으고**, **AI가 글과 댓글 맥락을 바탕으로 가치를 판단·정제**한 뒤, 사용자 상황에 맞는 **맞춤형 핫딜 추천**까지 이어지는 서비스를 기획하게 됨.

---

## 2. AI 활용(사용 모델 총 3가지)

본 프로젝트는 기획 단계부터 데이터 정제와 검색 경험 향상을 위해 **Google Gemini AI 생태계**를 도입함.

### 2-1. 데이터 수집·정제 (`gemini-3-flash 활용`)
* **도입 배경:** 미가공 핫딜만으로는 광고·바이럴·스팸을 안정적으로 걸러 내기 어렵고, 모든 글에 곧바로 LLM을 적용하면 비용과 지연이 커짐. 이에 **검증·키워드 규칙으로 1차 축소**한 뒤 LLM으로 **점수화와 요약**을 수행하는 이단 구조를 택함.
* **원리 및 효과:** 수집은 **GitHub Actions**로 스케줄 실행되는 크롤링을 통해 이루어짐. 파이프라인에서는 **네이버 최저가 검증**, **스팸·광고·바이럴 관련 키워드 필터링** 등 **운영 측에서 수동으로 구성한 규칙**으로 1차 필터링한 뒤, 통과한 항목만 **LLM이 상품별 점수(추천수, 댓글반응, 원가대비 할인률 등 기준)를 매김**. **일정 점수 이상**인 경우에만 DB에 적재하며, 적재 직전 **AI가 상품 요약과 추천 이유를 함께 생성**해 **DB 신뢰도와 노출 품질**을 높임.

### 2-2. AI 기반 검색 및 맞춤형 추천 (`gemini-embedding-001, gemini-2.5-flash 활용`)
* **도입 배경 – `ilike`로 시작:** DB에서 `ilike '%단어%'`처럼 쓰면 **글 안에 그 글자가 들어 있는지만** 본다는, 말 그대로 **문자열 부분 일치** 방식임. 구현은 단순하지만, DB에 적힌 단어와 검색어 표기가 조금만 달라도 **못 찾는 경우가 많아지고(재현율 저하)**, 한 단어가 넓으면 **관계없는 글까지** 걸리기도 함. 또 **문장째로 질문**하는 입력과 글을 잘 이어 주지 못했음.
* **개선 – 벡터 검색이란:** `gemini-embedding-001`이 제목·카테고리 등 **텍스트를 숫자 여러 개로 펼친 값(임베딩 벡터)**으로 바꿈. **뜻이 비슷한 문장은 숫자 묶음의 패턴도 서로 가깝게** 나오기 때문에, `ilike`처럼 글자가 똑같이 겹치지 않아도 **의미가 가까운 핫딜**을 골라낼 수 있음. 이걸 **벡터값(의미) 검색**이라고 부름. DB에는 미리 벡터를 넣어 두고, 사용자 입력도 같은 방식으로 벡터로 만든 뒤 Supabase `pgvector`에서 **코사인 유사도**로 가까운 순을 매김. 질문 해석·맞춤 추천에는 `gemini-2.5-flash`를 함께 사용함.

## 3. 시스템 아키텍처 개요

* **프론트엔드:** Next.js 15(App Router), React, TypeScript. 스타일·UI: Styled Components, Framer Motion, React Swiper. 화면 상태는 클라이언트 컴포넌트의 React 상태로 관리.
* **백엔드·BaaS:** Next.js Server Actions로 서버 측 로직 호출. Supabase(PostgreSQL, `pgvector` 확장) 연동.
* **데이터 파이프라인:** Python 크롤러를 GitHub Actions로 스케줄 실행. 정규화 → 최저가 검증·키워드 필터 등 규칙 단계 → LLM 점수·요약·추천 이유 부여 → 임계 점수 이상만 DB 적재.
> **크롤러 저장소:** [HOTDEAL_SCRAPER](https://github.com/RohUkJin/HOTDEAL_SCRAPER)

## 4. 프로토타입 구현 기능

* 전체 상품 기준 **베스트 10** 노출
* **카테고리별** 베스트 10 노출
* **전체 상품** 목록 조회
* 전체 상품 **필터링**
* **사용자 추천 검색**

## 5. 기술 스택
* **Client:** Next.js 15, React(TypeScript), Styled-Components, Framer Motion
* **Backend:** Next.js Server Actions 
* **DB/BaaS:** Supabase (PostgreSQL + pgvector)
* **AI:** Google Gen AI SDK (Gemini)
